Calibration test worksheet

Use this if you choose to measure an Energy or Rapid Shot AUG setup later. You can leave either calibration untested. This worksheet does not craft, equip, save a build, or import anything into Forge. Do not use a one-time blueprint just to fill it in.

Three simple steps

  1. Write down the exact weapon, gear, mods, Tech level, target and game version. Write unknown when you do not know.
  2. For each setup you actually test, record the time and reload before calibration or mod effects. Separate body, crit and weakspot hits from ordinary Power Surge triggers and AUG orb events. Mark each number Measured or Assumed.
  3. Review the record, then download JSON. Nothing is sent to the server. Repeat a trial on the same target if conditions changed.

A screenshot value or hypothetical input is not a measured trial. Empty fields remain unknown; zero means you actually observed zero.

Optional questions this could resolve

Trigger chance: relative increase or percentage points?

Record the listed weapon trigger chance and the listed increase, then count eligible hits and ordinary Power Surge triggers at comparable stack states. A relative increase would be p × (1 + r); a point increase would be p + r. Neither rule is verified for this exact roll. Do not count AUG orb impacts as ordinary triggers.

All DMG Boost: which bucket?

If two otherwise matching states are naturally available, record normal body damage without and with that roll against the same target. Keep target-category bonuses, range and buffs unchanged or describe what differed. The observed +3% line does not establish an independent global multiplier.
