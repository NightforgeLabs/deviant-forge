# Timed packet hook coverage

The six frozen v4.1 packet timelines now run inside Structured Compare's optional `context.integrated_combat` event scheduler. Set each side's `weapon_proc.weapon_id`, evidence mode, stable stream ID, `source_actions`, Attack/Psi `damage_model.basis_values`, and any needed `packet_hypotheses` for an unknown class, element, or keyword pool. A hit action uses `shot_event_id` so its timestamp is taken from the modeled firing schedule; resource observations and orb ticks require explicit `at`. No action creates a bullet or target. Duplicate hit-kind links to one shot are rejected. Source previews require `preview_simulation` and remain unverified for the current game. Structured Compare has a button that fetches each binding's exact required inputs and hit-coverage policy.

Every modeled direct shot is a landed hit. Hammerhead, Boom! Boom! and Holographic Resonance therefore require one corresponding source hit action per scheduled shot, including hits on which a cooldown or condition emits no extra packet. Critical Pulse, Pyroclasm and Pathfinder allow an unlinked ordinary shot only when `weapon_proc.ineligible_shots` explicitly maps its event ID to that binding's named reason: `no_observed_charge_spent`, `ordinary_uncharged_round`, or `ordinary_uncharged_shot`, respectively. An unlinked Holographic shot cannot silently bypass its counter. Missed shots are not represented by this direct-hit scheduler and cannot be used as an exclusion while still counting direct damage.

| Weapon | Executable hook | Entered inputs required beyond direct shots | Conditional modeled output | Remaining source gap |
| --- | --- | --- | --- | --- |
| Critical Pulse | Orb start and resolved orb ticks | Observed charge, lifetime, first tick delay, endpoint policy, orb ID, tick target and distance | Direct packets plus each resolved 75% Psi Shock Status tick | Charge acquisition, lifetime and target choice are observations, not inferred |
| Hammerhead Shark | Power Surge affected hit and nearby chain targets | Affected-state bool, primary and nearby target IDs, class hypothesis | 80% Psi Shock per nearby target; full total withheld for unresolved main-target 150% meaning | Main target interpretation, target radius/cap |
| KVD Boom! Boom! | Hit explosion with source cooldown | Explicit explosion target IDs and class hypothesis, preview opt-in | Preview 300% Psi Blaze packet per resolved target | Current coefficient, radius and target selection |
| Pyroclasm Starter | Charged shot damage units | Observed charged-round balance and list of each damage unit, preview opt-in | Preview 95% Attack Blaze Status per resolved unit | Charge conversion, pellet unit and current coefficient |
| SKS Pathfinder | Charge-consuming pierced targets | Observed charge, entered charge cost, target list, preview opt-in | Preview 110% Attack Frost Status per resolved target | Charge acquisition, target count and current coefficient |
| Holographic Resonance | 11-hit counter area pulse | One linked hit per shot, counter overflow policy, pulse target IDs on trigger, element hypothesis, preview opt-in | Preview 800% Attack Weapon per resolved target | Current counter/radius, target choice and element |

All six use a generic source action adapter and the same timed packet pool evaluator. The matrix records operator integration, not a verified current numerical profile. `GET /api/weapon-timeline-coverage` exposes the required caller inputs and evidence status per binding. Unknown source packets leave a known subtotal and a null complete modeled total. None of these six bindings emits a complete sourced Fire Rate or Reload Efficiency stat modifier, so no timing feedback was silently applied. Weapon-generated timing stat events outside the supported adapter remain unresolved until a source rule supplies magnitude, lifetime and event order.
