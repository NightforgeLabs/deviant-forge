# Builder upgrade inputs (2026-10-22)

The character Build editor records chosen equipment settings without turning unknown upgrade scaling into calculated damage. Click an equipped card to open its settings panel. Existing `level` values in older saved plans remain in the database and can be seen under **Advanced**; new selections do not create an unexplained equipment level.

| Input | Editor range and meaning | Evidence and limit |
| --- | --- | --- |
| Craft tier | Unset or I–V for selected weapons and armor | [Current client-derived blueprint pages](https://oncehuman.th.gl/db/blueprints/13222301) list crafted versions at tiers 1–5. This is a crafted-item tier, distinct from a mod level. |
| Blueprint stars | Unset or 1–6, narrowed by catalog rarity: legendary 6, epic 5, rare/fine 4, common/uncommon 3 | The [current game-file-derived blueprint index](https://oncehuman.th.gl/blueprints) lists Legendary 6, Epic 5, Fine 4, and Common 3. The builder maps its older rare/fine and uncommon/common labels by color class; item-specific blueprint validity still needs catalog confirmation. Older saved selections above a displayed cap remain visible as **Saved · verify**, without deletion. |
| Calibration blueprint | Optional name/style and optional actual roll description for weapons | The [official January 2026 update](https://www.oncehuman.game/m/news/devBlog/20260113/40781_1281545.html) says calibration-blueprint attributes apply when crafting and random bonuses vary by blueprint and rarity. Free text preserves a real roll without pretending a known stat profile. |
| Legacy enhancement | Unset or +0–+10 for a retained older weapon, with rarity caps: legendary 10, epic 7, rare/fine 4, common/uncommon 3 | The [official update](https://www.oncehuman.game/m/news/devBlog/20260113/40781_1281545.html) removed old enhancement for new crafting and retained existing calibrated stats. The historical rarity caps are [community corroboration](https://www.reddit.com/r/OnceHumanOfficial/comments/1erwvw7/), not a current official tier table. The field is never assumed for a new weapon. Older saved values beyond a displayed cap remain visible for review. |
| Attached mod level | 1–17; badge beside each attached mod opens the active mod's level control | The [official Field Guide overhaul](https://www.oncehuman.game/news/devBlog/20251212/40781_1276354.html) establishes the current system's 17-level table. Entry-specific obtainable levels and exact numeric profiles remain incomplete. |

No tier, blueprint star, calibration roll, or legacy enhancement is silently applied to the damage engine. Even when such a setting is the same in both plans, the current unlabeled SN700 source profile cannot be mapped to that crafted item, so its scoped reference winner is withheld. A comparison changing these settings also names their unresolved scaling. Planned settings do not mark catalog items owned.
