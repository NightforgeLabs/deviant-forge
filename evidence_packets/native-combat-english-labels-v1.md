[`trace_native_combat_english_labels.py`](trace_native_combat_english_labels.py) joins exact typed affix fields, validated localization-object pointers, and the installed English TID map. It inspects all **413 indexed affix prototype rows** with zero rejected name/format rows. [`native_combat_english_crosswalk.json`](native_combat_english_crosswalk.json) records row bounds, source-copy hashes, localization-object offsets and English-map pair offsets for every selected row. The pinned English copy is `translate_data_en.pinned.pyc`, SHA-256 `0bd9092f37c3fc4b3d771be76018cef66796e45ce7ca824dfb599a94a1117f95`; the affix source copy is `affix_prototype_data.pyc`, SHA-256 `a5732321ba5f84fa62fbfca910be49a93a26723d361a43afa28ea1a906d45d17`. No game code was executed and no installed game or Forge file was changed.

The installed English map also contains native translation keys `元素伤害` → “Elemental DMG” (pair offset 21056365), `元素伤害加成` → “Elemental DMG Bonus” (21133660), and `元素增伤` → “Elemental DMG Bonus” (20626290). **None of the 413 affix prototype name or format fields joins an “Elemental DMG” label to one affix ID.** The official S4 preview card for Elemental Resonance `<Aero>` uses “Elemental DMG” in a main/Flash effect, and a recorded current Field Guide card for Elemental Overload `<Resonance>` uses “Element DMG (Blaze, Frost, Shock, Blast) +18%”; those are effect descriptions, not proof of a single native `E34` attribute. `E34`'s exact installed affix label is **Shock DMG**. A generic Elemental DMG effect may affect several typed elemental properties or another producer, but its runtime mapping is not established by this crosswalk.

**Classification rule for DV:** Preserve the exact native affix code or typed property ID when present. English text alone is insufficient for “Weapon DMG” because `D0102/D01` and `E4200/E42` collide. “Status DMG” on `E4300` identifies a Dot subtype, while “Shock DMG” on `E3400` identifies lightning. A compound mod tooltip such as “Melee, Weapon, Status DMG” or a generic “Elemental DMG” effect needs its own native producer/effect join before assigning buckets. A correct label join also does not prove that a particular item affix is active or that the AUG executor assigned a keyword damage leaf.
