# Deviant Forge

**Once Human Build Advisor**

A local inventory and build workspace. Its game catalog is independent of your account recording; the recording supplies ownership, level, variant, equipped state, and variable roll evidence.

## Start

On this Omarchy desktop, run `./install-desktop.sh` once. Then press **Super+Space**, search **Deviant Forge**, and launch it. The per-user desktop entry starts the localhost service on demand and opens the default Chromium-family browser in app-window mode; Firefox uses a normal window. Repeated launches reuse a healthy server. After reboot, the first launch starts it again. On this Hyprland desktop, each browser window is launched silently onto an empty workspace from 1–9; workspace 10 is reserved for the game. If safe routing or a supported browser is unavailable, the server remains ready and the window launch is deferred. See `AGENTS.md` for the workspace rule that also governs tests.

For terminal use, `./launch.sh` still runs the server in the foreground at `http://127.0.0.1:8765`. Set `OH_ADVISOR_PORT` or `OH_ADVISOR_DATA` for that manual path. The desktop service uses port 8765 and the existing default `data/` directory. Requirements: Python 3, Pillow, FFmpeg/ffprobe, Tesseract, curl, and user systemd. Existing recordings and saved data stay in place.

## Workflow

Open **Mods** from the builder tabs at any time, without selecting equipment. **All Mods** shows the mods present in the local catalog; grey cards are not recorded in your collection and do not mean locked in game. Click one to add it to **My Mods** without equipping it. Its level and rolls remain unknown until separately recorded. Hover or focus shows details; an owned card offers a level field and a confirmed removal of a manual collection mark. Removing and adding that mark restores the same saved instance. Builds are unchanged. The catalog is not claimed to cover every live-game mod.

1. Start in the **loadout screen**. The character is on the left; a compact combat readout occupies the center; two wide firearm slots, a tall melee slot, and six armor slots are grouped on the right. Click an empty slot to open saved compatible gear and an inline **Find Gear** search beside the card, while the loadout stays visible. Search a name such as AUG, choose a variant, and set craft tier and blueprint stars in the local panel. **Add** saves a configured item. From then on, one click on that saved item in Choose gear equips its saved settings in the active build; **Edit / upgrade** opens separate controls. Catalog preview and Add remain explicit. Search, preview, and hypothetical Equip never claim ownership. Clicking an equipped card opens its controls beside that card; **Choose another** returns to the local chooser. Unequip and swaps retain saved gear; Recycle archives only the chosen local entry and preserves builds. **Saved gear** remains available as a broader collection view. Mods retain their own Field Guide level control. Selecting a mod socket asks for a damage goal, then shows **Best overall** catalog matches, **Best with your gear** recorded instances, and **All Mods** from the compatible catalog. The chooser uses family and variant cards, a current-weapon preview, and a detail panel beside a hovered or keyboard-focused mod; the same detail appears for an equipped mod badge. Escape dismisses the hover detail, while Equip and Unequip remain explicit. These are wording and evidence matches, not proven DPS or best-in-slot rankings; preview never changes the build and Equip remains explicit. The center readout accepts current weapon Attack and fire rate from the game tooltip and calculates a labeled theoretical direct-fire burst rate; magazine and reload time add a sustained direct-fire rate. The inputs are saved with that gear setup in the planned build. For AUG - Electron Cloud at craft tier III, the user-supplied crafting preview shows 101 DMG and 720 RPM, or 1,212 theoretical direct-fire damage per second; its star count and equipped result are not confirmed, so it is labeled as a separate reference, never as the damage of your saved six-star weapon. Optional calibration blueprints keep name, rarity, style, fixed effects, exact rolled bonuses, and a separate recorded upgrade level on a saved instance. The three screenshot examples prefill a proposal only; Add or Save is required to record it. Unknown stats, proc damage, crits, and conditional effects remain unknown. The top bar keeps Build, Compare, Library, Open, Save, and secondary actions. Expanded effects and build analysis are available on demand. The [upgrade input guide](BUILDER_UPGRADES.md) records ranges and source limits.
2. In **Import & review**, select a video range and native-resolution crop around the item cards and tooltips. Recognition matches titles and variants, reads level badges, and checks unlock, selection, hover, and equipped cues separately. Exact Field Guide mod title + level + Equip action saves an unlock; uncertain ownership and OCR stay in review with source frame and timestamp.
3. Catalog lookup supplies effect candidates, official mod tier positions, and verified numeric attributes for the currently resolved variants and levels. The original OCR lines remain attached to their sighting for audit. Unverified tiers stay blank; legacy random-roll mods need instance evidence. Conditional bonuses remain separate from their base values.
4. In the Build editor, **Duplicate**, change a piece or mod, **Save**, then **Compare** the two saved planned versions. The comparison lists changed gear, mod effects, level-dependent attributes, conditional activation, affected damage components, and set thresholds. Where the selected weapon has a sourced reference profile, enter encounter conditions for a scoped primary-fire burst/sustained estimate. The supported SN700/Distant Strike/Elemental Resonance comparison includes reload timing and changes recommendation with target distance. The source profile has an unlabeled in-game tier, so the estimate is not your crafted weapon's damage or a full-build DPS winner. See [BUILD_DAMAGE_MODEL.md](BUILD_DAMAGE_MODEL.md). The separate **Compare** page retains confirmed-inventory loadout and contextual measured-baseline tools; combat hits never transfer between gear combinations.
5. **Upgrades / farming** reports benefit unknown for an unmodeled change. Enter acquisition activities linked to a build target to use the time-budget session planner.

## Evidence and limits

The [official Field Guide update](https://www.oncehuman.game/news/devBlog/20251212/40781_1276354.html) establishes account unlocks and the ordered level 1–17 subattribute tiers. The [official January FAQ](https://www.oncehuman.game/news/devBlog/20260123/40781_1283429.html) describes shiny mod behavior and crate level ranges. The broader catalog uses a dated [Apache-2.0 community snapshot](https://github.com/lReDragol/OnceHuman_Tools/tree/d6b1d5b99f84cb6ddc6b8f85144ee067af2a4e45) plus a [current community mod index](https://www.oncehumandb.com/mods) with explicit status labels and conflict flags. Official current rules in `rules.json` govern the narrow calculation cases they actually support. See [CATALOG_SOURCES.md](CATALOG_SOURCES.md) for provenance, [STATUS.md](STATUS.md) for exact coverage and missing mechanics, and [RECORDING_REVIEW.md](RECORDING_REVIEW.md) for the real import result.

The SQLite database keeps media, observations, inventory, planned builds, loadouts, upgrade targets, activities, and contextual measurements separate. Schema version 6 migrates older databases. Backup format version 8 also preserves Field Guide profile levels, their event history, and undo records. Older backup versions did not contain those three tables; restoring one leaves current Field Guide and undo rows in place. Backups include source crops and measurements; they may contain private images. Original video files above the backup size cap stay in the local media directory.

## Validation

The Compare page now has an unsaved reviewed-row calculator for arbitrary gear, mods and builds. It shows bullet, crit, weakspot, status and named proc sensitivities, condition ranges, optional firing-cycle throughput, and measured-run totals separately. Its pool stacking is an explicit hypothesis; it never declares a full game DPS winner from incomplete mechanics. See [component comparison and coverage](COMPONENT_COMPARISON.md). The user-invoked Super+Space launcher opens on the user's current positive numbered workspace. Assistant tests leave the game on workspace 10 untouched.

Run `python3 -m unittest discover -s tests -q`, `node tests/ui-character.cjs`, `node tests/ui-builder.cjs`, `node tests/ui-combat-formula.cjs`, `node tests/ui-smoke.cjs`, `node tests/layout-check.cjs`, `python3 tests/hotspot-geometry.py`, and `node --check` on changed JavaScript files. The character and builder UI tests exercise controls through isolated loopback HTTP servers and temporary data; the formula UI test covers the guided journey and stale-result guard. These loopback tests may need local-socket permission. The hotspot test checks native image coordinates and target geometry at 1280px and 3440px. None replaces a rendered browser review. `python3 tools/import_official_mod_cards.py --check` and `python3 tools/audit_detail_magnitudes.py --check` verify the reproducible evidence indexes. `desktop-file-validate ~/.local/share/applications/deviant-forge.desktop` checks the installed launcher. To reclassify already extracted crops, run `python3 tools/reconcile_recording.py`, then `python3 tools/write_recording_report.py`. These do not reencode or edit the original recording.
