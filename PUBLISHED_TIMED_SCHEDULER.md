# Guided published-reference event bridge

The optional **Linked source timeline** in Compare now derives ordered shots and reloads from a selected published weapon's RPM, rounded magazine, and reload seconds. It requires an entered finite reserve, named target and one explicit chance roll per generated shot when that source weapon has a chance rule. A deterministic counter needs no roll sequence. The source runner owns chance, counter, cooldown, periodic and weapon state events; the shared scheduler owns bullets, reload timing and selected mod/set pools. Each direct shot is counted once. The crit/weakspot expectation is applied to the direct packets after scheduling, while source packets retain their own source or entered classification.

The connected path covers the nine representative bindings in `weapon_mechanics/bindings.json` and six packet-hook bindings through `published_packet_recipe.py`. Concrete tests exercise Outer Space's 12-hit lightning, Crank's historical Burn periodic model, Hazardous Object's capped reload blast from twelve actual remaining rounds, and a selected Status mod plus Bastille reload efficiency. The additional hooks link every generated shot to an explicit action or named uncharged exclusion. Critical Pulse needs one observed charged shot, orb lifetime, tick times and distance; Hammerhead needs a Power Surge flag per shot and affected target IDs; Boom! Boom! needs explosion targets; Pyroclasm and Pathfinder need observed charged shot indices, resource counts and resolved target or damage units; Holographic needs pulse targets and a named counter overflow assumption. The guided Critical Pulse path supports one orb; overlapping orbs use advanced events.

## Named scenario controls and limits

- Published damage, RPM, magazine rounding and reload seconds are **calculator reference inputs**, not measured crafted weapon stats. Reserve bullets, target identity, chance outcomes, affected-state sequence, extra packet basis/class/element/targets and missing coefficients are explicit scenario inputs. A source preview needs preview mode.
- The guided reload-blast policy requires an entered early-reload shot count. It consumes the remaining modeled magazine. It uses an explicit **no refund** outcome because the refund destination and rounding remain unresolved; no bullets are created.
- The six packet-hook paths reuse published shot and normal reload times, finite ammo, selected pools and the existing source packet evaluator. They do not infer charge collection, nearby/area targets, orb tick cadence, current preview coefficients or missing class/element. Hammerhead's main-target 150% interpretation stays unresolved, so its guided result is a subtotal even when a chain target is entered. Boom! Boom!, Pyroclasm, Pathfinder and Holographic use historical preview evidence only in an explicitly selected preview scenario.
- Direct crit/weakspot shares are an expected mixture independent of the entered proc outcomes. Correlated crit-trigger mechanics need a richer joint-hit model. Source packets with unresolved crit eligibility, class, target or coefficient remain in the known subtotal and withhold a complete total.
- Selected main-effect ranks without a Field Guide level mapping are **not** treated as numeric buffs. A mod with all four numeric bonus lines still withholds the complete timed total if its main effect is not connected. Supported source-checked static main effects can enter the named pools once; utility, timed or conditional outputs require their own event operator. Bonus lines unsupported by the named pools remain unresolved. Source release dates, historical previews, current target resistance/mitigation and universal bucket order remain caveats, not a verified game winner.
- A complete same-duration modeled comparison additionally requires the same entered source target on both sides and an explicit shared-target confirmation. A conditional modeled ratio never becomes a game-verified winner.

The public mod detail source descriptions and their 64 unmapped core-effect variants are separate from this scheduler. The two unsourced Resistance four-line layouts remain unknown.
